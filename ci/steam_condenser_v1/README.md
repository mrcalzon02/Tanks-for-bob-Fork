# Preserved development harness — not production integration

This test harness and the V1 condenser model were created during the paused
structure-production discussion. They have **not** been run as a successful
native integration and do not promote any graphics. The owner questioned the
unfamiliar model. Preserve it for provenance; do not silently install it or
call it the compressor.

The existing `steam-condenser` entity is genuinely placeable and unlocked in
Tanks. Its `Steam-condenserA` recipe consumes wood and steam and produces stone
and industrial waste. The proposed model is an unapproved graphic candidate
for that entity, not evidence of a completed installation. The Tech-Priests
atmospheric condenser V24 is a separate machine.
