# Third-party graphics source research and attribution

## Snouz — Factorio Free Graphics for Modders

Collection: https://github.com/snouz/factorio_free_graphics_for_modders

**Credit to snouz for compilation and indexing**, and to each original creator for their artwork. This collection is a **mixed-license resource index**, not a license grant covering the entire repository. Its README specifically requires checking each image's original mod license and giving credit. Some entries are Wube EULA/restricted, CC BY-NC-SA, GPL/LGPL, MIT, CC BY and public domain; some images are reworks or AI-generated. Do not use the repository name as a reason to assume an image is redistributable.

For campfire and other island-survival art, search by filename for the actual needed image (stone, clay, bark, wood, ashes, glass, crystals). Validate the specific asset's source, license and appearance before selectively adopting it. Avoid large copied catalogs. A listed icon is not necessarily a Blender texture or complete sprite animation.

## Malcolm Riley — Unused Renders

Artist: Malcolm Riley. Repository: https://github.com/malcolmriley/unused-renders ; tutorials: https://github.com/malcolmriley/unused-renders/wiki . Art is CC BY 4.0, requiring source, author, license and modification attribution. Its renders are generally item sprites, not seamless 3D material maps.

## Required asset ledger

Before each actual reuse: record exact original file URL/revision, author, applicable license, modification or adaptation, our destination file, test result, and whether the active sprite is switched. Merely consulting the collection as a reference is not an import.

Campfire V6 uses original procedural textures; no upstream art has been copied into this V6 pass. The independently staged earlier Unused Renders icon candidates retain their own credits.
