# Tank Assembling Machine V1

The actual Tanks `tank-assembling-machine` is a 3x3 electric 250 kW vehicle
upgrade assembler, speed one, four empty module slots, ingredient limit six.
It has no burner, fluids or pipe connections. All four requested directions
normalize to north and native rotate returns false. One actual art orientation
is exported. Ten generic engine parameter placeholders are excluded.

All thirteen real recipes are in the preserved native contract. They upgrade
existing tanks and one car with actual arms, encabulators, electronics and engine
parts; three WLSK variants consume a light chassis. The chassis recipe uses
processing units, electric engines, TurboEncabulators and Alumatedplates, and
returns industrial waste as well as a chassis. The longest WMD upgrade takes
3040 seconds. Tests retain actual recipe times, speed, power and empty modules.

The building consumes an ammunition assembler, an Encabulator, three Cradinal-
grametters and an Alumatedplate in the tank-ammo-component category, gated by
encabulated-device-integration. The native proof crafts it in the delivered
ammunition assembler, checks item/place_result and ordinary player-grid placement,
then consumes the actual crafted item for the placed prototype. This is a native
scripted placement, not a claim of manual player clicking.

All nine starter groups are preserved. The stone/timber bed supports retained
rails, seated timber gantry feet, knee braces and cantilevered winch bearings.
The input vehicle has an open plated hull, tracks, road wheels with through axles
and actual bored hull openings, seats and bulkhead. An upright replacement
engine hangs from a spreader and fixed-length slings. The supported exposed
wound electric motor reverses a rigidly coupled winch; ropes remain attached to
the upright load and fixed fairleads. A bored carriage follows its fixed rail,
carrying the retained joining head, ceramic collar and real electrode. The small
joining effect is rooted at the actual electrode/workpiece seam. Two rigid
insulated electrical arms have separate hinge planes and fitted axial pins.
Leads use supported clay insulators and clear the timber and moving machinery.
No pressure vessel, pipe process or burner gameplay has been invented.

Surfaces combine physical per-part grain/end-cut UVs and useful shared base
metal maps with model-specific limestone, rope, winding cloth, oxide-green
scuffed vehicle plate and glazed insulators. A new filename alone is not claimed
as material authorship. Packed source is saved/reopened; the actual GLB is
independently reimported, measured in six poses and viewed front/rear/side/clay/
mechanism close. Both source and GLB are swept at 193 keys plus 192 half-frames.
Raw triangle contacts remain complete and are explicitly adjudicated; these are
sampled checks, not continuous collision simulation.

There are 33 genuine source captures: one idle and 32 working frames for north.
The idle capture is repeated explicitly into 32 atlas cells because the native
assembler requires matching idle/working frame counts. No extra idle captures
or supported directions are claimed. Runtime animation_progress is explicitly
one; Factorio's default 0.5 otherwise halves the intended eight-fps playback.

Forty-six genuine client screenshots include 32 distinct motion phases at eight
fps, plus idle, no-power, blocked, stop/restart, resupply, crafted placement and
long-recipe completion. Paused and blocked machine pixels are unchanged between
observations; working pixels move. The actual completed operated save passes a
300-tick reload after a sixty-tick disabled settle, retaining inventories,
progress/counters, electric buffers and the crafted building. Final source and
canonical publication receipts accompany delivery. No individual owner approval, full user mod-pack installation or Mod
Portal publication is claimed. Earlier local studies remain held.
