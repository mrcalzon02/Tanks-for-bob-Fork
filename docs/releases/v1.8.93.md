# Tanks! for Bob Fork v1.8.93 — Factorio official-module compatibility audit

**Factorio package target:** **2.0**. Contains installable mod archive `tanks_for_bob_fork_1.8.93.zip`; install the ZIP in Factorio's `mods` folder without unpacking. This is a **GitHub release**, not a Mod Portal upload.

## New compatibility coverage

The [official-module test suite](https://github.com/mrcalzon02/Tanks-for-bob-Fork/actions/workflows/vanilla-factorio.yml) verifies **12/12 headless engine profiles** plus a static source audit inside **ONE GitHub Actions job**.

- **Factorio 2.0.77:** Base; Base + Elevated Rails; Base + Quality; Base + Rails + Quality; Base + Space Age (with official components).
- **Factorio 2.1.23 probes:** Base; Base + Rails; Base + Recycler; Base + Quality + Recycler; Base + Rails + Quality + Recycler; Base + Space Age without Quality; Base + all official expansion components.
- The Factorio **2.1 matrix changes the mod version metadata in CI's disposable copy only**; this release's ZIP remains **Factorio 2.0-tagged**. No standalone 2.1 build is claimed.

### Headless audit evidence

- **210** declared recipes and **88** technologies registered; **0** source-declared disabled recipes lacking unlocks.
- **210/210** ingredient chains reached by an *optimistic* recipe graph. This is **not proof of real factory/research progression**.
- **13** vehicle definitions, **26/26** mounted gun-to-ammo-category matches, **13/13** declared ammo items and corresponding recipe output checks.
- Engine simulation spawned **8** vehicles at tick 300, caused **1,250→0** physical hitpoint damage at tick 600, and inserted matching ammo into **7/7** surviving vehicles at tick 900.
- All 12 profiles also created a deterministic save, simulated 1,200 ticks, and started a private dedicated server.
- Corrected import capitalization, duplicate categories, graphics paths, recipe icon references and 2.1 prototype API assumptions. Original high-resolution turret artwork restored.

### Limitations

These are **headless smoke tests**. They do not yet prove live projectile firing, ammunition consumption, client graphics, full research and production, functional tank recall, two-player multiplayer, save migration or combat balance. The recall event handlers remain commented out.
