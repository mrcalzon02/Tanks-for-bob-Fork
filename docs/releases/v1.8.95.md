# Tanks for Bob Fork v1.8.95 — island-survival recipe repair

**Factorio target:** **2.0**, with Base + optional official Elevated Rails,
Quality and Space Age. No Factorio 2.1 standalone build is claimed.

## Fixed
- Primitive **Workbench** ingredient limit raised from 2 to 3, covering
  `clay-pit`, `wood-basin`, `fish-pond`, `quarry`, and
  `primitive-steam-powered-pump`.
- **Cooking Fire** now has a north steam input, enabling the two existing
  steam-based recipes, notably `rendered-organics`. All original
  research prerequisites and recipe quantities remain unchanged.
- Dedicated **Tank Ammunition Assembler** now exposes an input and output
  fluid port so its crude-oil-generating/consuming recipes can operate.
- The existing **one-job, one-Factorio-profile** headless audit gained
  nine machine-to-recipe/category/fluid feasibility checks.

## Source-controlled geometry (not in the mod ZIP)

An initial **21-structure low-poly 3D OBJ library** for the island survival
and early industrial stages is available in the GitHub repository:
[models/island-survival](https://github.com/mrcalzon02/Tanks-for-bob-Fork/tree/main/models/island-survival).

The meshes can be imported and refined in Blender; each references its
source sprite. They are **greybox models**, not approved sprite-matched final
art and not runtime game replacements.

## Remaining verification

These repairs pass initial engine/prototype checks only when CI confirms
them; full player-driven survival/research progression, real ingredient/
fluid consumption, visual sprite/model matching, and functional recall
remain separate tasks.

[Run the single Factorio compatibility workflow](https://github.com/mrcalzon02/Tanks-for-bob-Fork/actions/workflows/vanilla-factorio.yml)
and read the [full recipe/technology audit](https://github.com/mrcalzon02/Tanks-for-bob-Fork/blob/main/docs/compatibility/RECIPE_TECH_LOGICAL_AUDIT.md).
