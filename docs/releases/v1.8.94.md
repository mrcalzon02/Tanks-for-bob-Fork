# Tanks for Bob Fork v1.8.94 — Factorio 2.0

**Distribution:** Factorio Mod Portal and GitHub Release.

This is the next version after 1.8.93, with the accumulated Factorio 2.0
compatibility repairs, weapon/ammunition prototype validation, and corrected
source and asset references.

The current automation uses **one GitHub Actions job and one Factorio 2.0.77
profile** with Base + Elevated Rails + Quality + Space Age enabled together.
It validates actual game loading, recipe/technology registries, vehicle
instantiation, 1,200 runtime ticks, real damage response, ammunition
inventory insertion, and private headless server startup.

The previous extended 12-profile Factorio 2.0/2.1 tests are retained only
as historical evidence. This package's `factorio_version` remains **2.0**.

**Not verified:** firing projectiles and ammo consumption, graphical-client
appearance, player driving, live two-player sync, full industrial/research
progression, recall controls, or save migration.

See [current testing](https://github.com/mrcalzon02/Tanks-for-bob-Fork/actions/workflows/vanilla-factorio.yml)
and [the audit document](https://github.com/mrcalzon02/Tanks-for-bob-Fork/blob/main/docs/compatibility/CURRENT_STATE_AUDIT.md).
