## Verified development progress and coverage

1. **Gameplay/progression.** The 1.8.102 native test evidence records 213 custom recipes, 90 technologies, 14 ammunition definitions, and 16 machine regression cases. Fish Resource Recovery, starter wood, split special ammunition research, existing-save migration, machine capacity, ordinary and advanced cooking, oil production, private server startup, and 1,200 simulation updates were exercised in the November 8 native Factorio 2.1.24 suite. Evidence: [suite results](../compatibility/evidence/1.8.102/suite-results.json) and [decision record](../compatibility/PROGRESSION_DECISIONS_1.8.102.md). **That exact November 8 ZIP proof does not automatically certify subsequently modified art.**
2. **Later official-profile engine test.** [Run 42893564032](https://github.com/mrcalzon02/Tanks-for-bob-Fork/actions/runs/42893564032) (10 November) successfully ran the one-job Factorio 2.1.24 compatibility profile after the Cooking Fire active-source integration. It predated Solar Boiler V8.
3. **Workbench V8.** The one-tile workbench four-way/96-frame real Blender-derived animation and south fluid output are present in the active `1.8.102` data-final-fixes and graphics, introduced by [commit 3f38f801](https://github.com/mrcalzon02/Tanks-for-bob-Fork/commit/3f38f801631a88460bca5599616edb0173f4a970).
4. **Cooking Fire V2.** Four-direction active graphics attachment, ordinary/advanced cooking behavior retained; [commit 5edcc537](https://github.com/mrcalzon02/Tanks-for-bob-Fork/commit/5edcc5372e8758b142bfd32c6869db838f41a736).
5. **Solar Boiler V8.** Accepted floorless Blender-derived sprites, `BoilerPictureSet` adapter, original 3×2 geometry and native fluid ports are installed in active source. [Factorio 2.1.24 native engine run 43120594298](https://github.com/mrcalzon02/Tanks-for-bob-Fork/actions/runs/43120594298) passed four rotations and **12/12 connected pipes**. [Placement receipt](../../models/island-survival/solar-boiler/generated-v8/factorio-placement-receipt.json) marks this engine smoke passed, but client visual acceptance **false**. Real in-game GUI screenshot attempt failed under Windows service Session 0, producing **0/16** expected screenshots; see [issue #4](https://github.com/mrcalzon02/Tanks-for-bob-Fork/issues/4). This is an unresolved *visual diagnostic*, not a demonstrated fluid-connectivity failure.
6. **Beach Pump V5.** Independent native Blender reopen and four-direction 68-frame candidate render receipts exist, including actual master source parts. The gameplay entity remains `offshore-pump/beachpump` at **0.01 water/tick**, original shoreline intake and south fluid output. The V5 art is **not installed in the active mod**, and owner/in-client sprite acceptance is **pending**. See [V5 audit](../../models/island-survival/beach-pump/generated-v5-review/README.md), [atlas QA](../../models/island-survival/beach-pump/generated-v5-review/candidate-atlas-qa.json), and [visual proof](../../models/island-survival/beach-pump/generated-v5-review/review-four-directions.png).
7. **Unfinished integrations.** Steam Condenser, primitive steam pump, and Bob's Mods compatibility remain tracked work, not certified components of this release candidate. See [issue #5](https://github.com/mrcalzon02/Tanks-for-bob-Fork/issues/5), [issue #6](https://github.com/mrcalzon02/Tanks-for-bob-Fork/issues/6), and [issue #1](https://github.com/mrcalzon02/Tanks-for-bob-Fork/issues/1).
