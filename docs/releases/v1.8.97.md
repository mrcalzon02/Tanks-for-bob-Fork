# Tanks for Bob Fork v1.8.97 — Clay Pit V4c (Factorio 2.1)

This update promotes the explicitly approved **Clay Pit V4c** native Blender artwork into the official `tanks_for_bob_fork` Factorio 2.1 release. The earlier Factorio 2.0 source and 1.8.96 Mod Portal release are not overwritten.

The clay pit is now a real directional structure with four fixed-camera 45° rendered orientations. When inactive, it shows the softly blended, excavated wet-earth basin. When working, it shows the rough wooden support, tiny warm wax-paper lantern with a subtle flicker, the shovel, and a water-filled wooden bucket that swings gently. The 16-frame loop is sampled at 8 FPS from 68 genuine Blender render captures (4 idle plus 64 working). The verified bucket swing reads at 4.4–6.71 pixels at 64px sprite scale depending on direction.

The new 128px idle and working sprite sheets are full-state alternatives (not stacked duplicate bases), with 16 frames for each of four orientations. Both are used at 0.5 graphics scale. The previous raw sprites remain in the package as a rollback path. Clay-pit entity, item, and technology icons are updated. The slightly rectangular collision box enables cardinal rotations; existing north/south pipe connections, recipes, wood fuel, sound and crafting behavior are retained.

This package is rebuilt from the previously validated 1.8.96 Factorio 2.1 full mod. The repository's native model and production documents remain reusable for later clay-derived structures. The `.github/workflows/clay-pit-v4c-factorio-21-release.yml` workflow packages the V4c Blender frames, loads the whole 1.8.97 mod in the real Factorio 2.1.23 headless engine, runs a short simulation, and only after a passing engine run uploads to the **existing Factorio Mod Portal listing**, without retagging older versions.

The user approved deploying V4c directly; visual and gameplay validation of this exact full-mod update in the graphical client remains a separate post-release diagnostic, not a release blocker when engine loading passes.
