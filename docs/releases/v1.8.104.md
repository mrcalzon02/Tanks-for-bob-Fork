# Tanks for Bob Fork 1.8.104 — Factorio 2.1

This release brings the integrated survival and manufacturing updates since
the Mod Portal's 1.8.100 release into one installable package.

## Included updates

- The complete current set of 21 survival and manufacturing structures, including
  the animated one-tile Workbench, Cooking Fire, Solar Boiler, Beach Pump,
  primitive pipe pump, Fish Pond, Steam Compressor, Wood Basin, Quarry, Shaler,
  Calcifier, Thinking Hut, Pondering Hovel, Stone Water Wheel, Tank Ammunition
  Assembler, Tank Assembling Machine, and Steam Condenser.
- Modeled material, fluid, module, and research icons.
- The 1.8.101–1.8.102 progression repairs: handcraftable starting spear and
  wood-acquisition discovery, Fish Resource Recovery, Workbench oil extraction,
  corrected Pit Kiln recipes, and appropriate poison-mine and artillery unlocks.

Factorio **2.1** is required. Elevated Rails, Quality, Recycler, and Space Age
remain optional dependencies.

## Package and verification

The release job builds the highest versioned production source into a single
deterministic ZIP and verifies every archived file against that source. It runs
the exact unmodified archive in official Factorio 2.1.24 to create a world,
reload it for 1,200 simulation ticks, and start a private dedicated server.
The attached receipt and logs record the observed results and package hashes.

Install `tanks_for_bob_fork_1.8.104.zip` in Factorio's `mods` directory without
unpacking it, or update through the game's Mod Portal interface.

The ZIP contains the current mod only. Historical source versions, Blender
projects, development captures, and CI tools remain outside the installable
package. Existing releases and tags are preserved.
