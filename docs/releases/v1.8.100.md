# Tanks for Bob v1.8.100 — Lumberyard name and preview correction

The user-approved V2b model fully replaced Growing Plot visuals in 1.8.99, but the old displayed building name and descriptions persisted. This patch applies the visible name **Lumberyard** to the existing entity, item, crafting recipe and research technology, using Factorio-supported `localised_name` fields. The English and English 40k overlay locale entries are updated to match.

The approved `lumberyard-v2b.png` 64×64 RGBA inventory image is already present on the entity/item/technology; this patch explicitly attaches the same real preview icon to the active crafting recipe and aligns the unused duplicate recipe source for consistency. NO sprites, animation data, gameplay mechanics, or previous release files are rewritten.

**Save compatibility:** The internal ID remains `growing-plot` in every prototype, recipe result, research unlock and placed-entity reference. Only the player-facing name/description is Lumberyard. No destructive migration, retagging, or existing save reset.

The release script asserts an exact eight-file change scope and checks every preserved Lumberyard PNG byte hash. The Github workflow rebuilds approved 1.8.99, generates 1.8.100, loads it under official Factorio 2.1.23 for map creation and 300 ticks, then uploads via the protected Mod Portal key. The previous campfire, clay pit and kiln remain included.
